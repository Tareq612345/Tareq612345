## Featured projects

### [WhatsApp Admin Bot](https://github.com/Tareq612345/whatsapp-admin-bot)

A local WhatsApp group-management project with an Electron desktop interface, block/allow lists, membership-request automation, student-card OCR, review dashboards, and Excel exports.

- **Stack:** JavaScript, Node.js, Electron, SQLite, and `whatsapp-web.js`.
- **Explore:** [Documentation](https://github.com/Tareq612345/whatsapp-admin-bot#readme) · [Releases](https://github.com/Tareq612345/whatsapp-admin-bot/releases)
- **Status:** Early-access desktop software. Uses WhatsApp Web automation, not the official WhatsApp Business API.

### [Masar Platform](https://github.com/Tareq612345/snu_web)

A web platform with modules for attendance, quizzes, community communication, notifications, and administration.

- **Stack:** JavaScript, Vite, Tailwind CSS, Firebase Authentication, Firestore, Storage, and Cloud Functions.
- **Explore:** [Project overview and setup](https://github.com/Tareq612345/snu_web#readme) · [Issues](https://github.com/Tareq612345/snu_web/issues)
